# Sebastians_Green_Functions
Green-Function Analysis of a small Example-System to illustrate the formalism (related to review article).



This is the code that was created as an example for the article

    https://iopscience.iop.org/article/10.1088/1361-6404/ae26fc

It is an easy "copy and run" script, in order to generate the plots from the article.

The underlying equations can be found in the article.
